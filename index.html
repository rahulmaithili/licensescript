🚀 Quick Supabase & Netlify Setup Instructions:

  1. Supabase SQL Database: Open your Supabase Dashboard → SQL Editor → Click New query → Paste and run the code from supabase_schema.sql (provided in the root directory).
  2. Enter Credentials: Copy your Project URL and anon public key from Supabase and paste them into the fields above, then click Save.
  3. Netlify Deployment: Push this folder to GitHub or drag & drop to Netlify. Netlify will automatically detect netlify.toml, the static frontend, and the serverless functions in netlify/functions/.
  4. Netlify Environment Variables (Optional for Webhooks): In Netlify Site Settings → Environment variables, add SUPABASE_URL, SUPABASE_ANON_KEY, RAZORPAY_KEY_ID, and RAZORPAY_KEY_SECRET.
